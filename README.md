# Abhishek Wali - Portfolio

A minimal, pixel-perfect dev portfolio built with modern web technologies.

## Overview

### Stack

- Next.js 15
- Tailwind CSS v4
- shadcn/ui

### Features

- Clean & modern design
- Light/Dark themes
- vCard integration
- SEO optimized (JSON-LD schema, sitemap, robots)
- Spam-protected email
- Installable as PWA
